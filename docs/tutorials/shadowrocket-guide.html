2026 最新 Shadowrocket (小火箭) 零基础新手导入与分流规则配置教程

📅 最后更新：2026年10月 📂 分类：iOS 客户端配置 ⏱️ 阅读建议：5 分钟

前言：认识 Shadowrocket (小火箭)

Shadowrocket（俗称“小火箭”）是 iOS 平台上最流行、功能最完备的代理工具之一。它支持包括 Shadowsocks、Vmess、VLESS、Trojan、Hysteria2 等绝大多数主流协议。

本教程专为新手编写，从安装下载避坑、导入订阅，到配置最省心智能的“配置 (分流规则) 模式”，助你一次性搞定顺畅出海。

一、 软件下载与安装避坑指南

⚠️ 致命避坑警告：
中国大陆地区的 Apple ID 无法在 App Store 搜到正版 Shadowrocket！国内搜索出来的均为李鬼恶意山寨盗版软件，切勿购买或下载！

正确下载姿势：

  1. 准备一个非国区 Apple ID（美区/港区/日区均可）；
  2. 打开 iPhone 的 App Store，点击右上角头像退出当前账号，登录海外 Apple ID；
  3. 搜索 Shadowrocket（开发者为 Pan modal，售价一般为 $2.99 美元）；
  4. 下载安装完成后，退出海外账号并切回你原本的国内常用 Apple ID，软件可永久正常使用。

二、 节点导入：一键订阅与手动扫码

要使用小火箭上网，必须配合稳定可靠的机场节点。

💡 内链导流推荐：
许多新手初次配置时因使用免费节点或劣质公网机场，导致小火箭提示“连接超时”或频繁掉线。推荐搭配使用本站实测推荐的 极光云 (Aurora) IPLC 全专线机场（晚高峰丢包低于 0.08%），订阅导入成功率 100%。

方法 A：一键导入订阅（最推荐）

  1. 登录你的机场用户后台（以 极光云 为例）；
  2. 在用户中心找到 “便捷导入” 或 “一键导入 Shadowrocket / 小火箭”；
  3. 点击后系统会自动唤醒 Shadowrocket 并弹窗提示是否保存订阅，点击 “保存” 即可。

方法 B：手动复制订阅链接导入

  1. 在机场后台复制订阅链接（以 https://... 开头）；
  2. 打开 Shadowrocket，点击右上角的 + 号；
  3. 在“类型”中选择 “Subscribe (订阅)”；
  4. 将链接粘贴至 “URL” 输入框中，并在“备注”中输入机场名称（如：极光专线）；
  5. 点击右上角 “完成”，软件将自动下载并列出几十个海外高速节点。

三、 核心设置：全局、配置 (分流)、直连模式区别

进入小火箭主界面，在开关下方有“全局路由”设置，新手必须弄清三种模式的区别：

  • 配置 (Config) 模式【强烈推荐】： 智能分流模式。访问国内应用（微信、百度、淘宝、B站）走本地直连，访问国外封锁网站（Google、YouTube、Netflix、ChatGPT）自动走代理节点。既省流量又保证国内 APP 速度飞快。
  • 代理 (Proxy) 模式： 所有网络流量不论国内外强行全部走代理节点。可能导致国内 APP 定位变到海外，并浪费大量机场流量。
  • 直连 (Direct) 模式： 不走任何代理，相当于直接裸连。

四、 进阶配置：针对流媒体与 ChatGPT 的智能规则

如果你经常使用 OpenAI ChatGPT 或收看 Netflix / Disney+，建议在小火箭底部菜单进入 “配置” 页面：

  1. 点击 default.conf 后的感叹号图标，选择 “规则”；
  2. 点击右上角 + 号添加分流规则： 
    DOMAIN-KEYWORD, openai, PROXY
DOMAIN-SUFFIX, chatgpt.com, PROXY
DOMAIN-SUFFIX, anthropic.com, PROXY
DOMAIN-KEYWORD, netflix, PROXY
  3. 确保指定分流规则指向支持住宅原生 IP 的地区节点（如美国或日本）。
💡 小提示： 选购机场时请参考本站整理的 2026 优质机场解锁矩阵，选择原生支持 ChatGPT 免手机验证的节点。

五、 常见连接报错与排错清单

1. 打开连接开关后，提示需要添加 VPN 配置？
初次使用系统会弹出系统授权弹窗，必须点击“Allow (允许)”并验证面容或开机密码。

2. 节点全部显示超时（Timeout）或 Ping 失败？
首先检查手机系统时间是否精准到“自动设置”，时间偏差超过 90 秒会导致 TLS 握手彻底失败；其次请阅读本站知识库的 《节点全部超时 5 步排查指南》。
