Clash Verge Rev 零基础实战配置教程：Meta/Mihomo 内核与 TUN 虚拟网卡实战

DATE: 2026-11-26 TAG: #ClashVerge #Mihomo #TUN模式

Clash Verge Rev 是当前 Windows、macOS 和 Linux 平台上最受欢迎的新一代现代化代理客户端之一。相比传统的 Clash for Windows，它原生集成了开源 Mihomo（Clash.Meta）内核，拥有更低的系统资源占用、更强大的协议支持（如 Hysteria2、VLESS）以及无缝的 TUN 虚拟网卡接管能力。

一、 客户端正版下载与基础安装

请前往官方开源 GitHub Release 页面获取对应操作系统的最新安装包：Windows 推荐选择 .x64.exe 安装包；macOS Apple Silicon 芯片（M1/M2/M3/M4）选择 arm64.dmg。

二、 导入机场订阅与更新节点

  1. 从你所购买的机场后台复制 Clash / Clash.Meta 订阅链接。
  2. 打开 Clash Verge Rev，点击左侧菜单栏的 “订阅” (Profiles)。
  3. 在顶部输入框粘贴订阅地址，点击 “导入”，等待下载成功后选中该配置文件。

三、 开启 TUN 模式接管系统全局流量

普通系统代理仅对支持系统代理解析的浏览器生效，命令行终端、开发工具（Git、Docker）以及部分客户端应用常常绕过代理。开启 TUN 虚拟网卡模式可以彻底接管底层所有 TCP/UDP 流量：

  • 点击左侧 “设置” (Settings) -> 找到 “TUN 模式” 开关并开启。
  • 首次开启需点击“授予管理员权限”，系统会自动安装虚拟网卡驱动。
  • 配合内置的智能分流规则（Rule Mode），实现国内流量直连、国外流量自动加速。

四、 故障排查与相关指南

如果在配置过程中遇到节点全部超时或无法联网，请参考本站排查文档：《节点全部超时与本地 DNS 污染排查全书》。
