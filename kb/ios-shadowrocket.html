iOS小火箭 (Shadowrocket) 零基础图文教程：正版下载、一键订阅与规则配置

DATE: 2026-10-11 TAG: #iOS小火箭 WORD COUNT: 约 1,300 字

一、 为什么 iOS 首选 Shadowrocket (小火箭)？

在 iPhone 与 iPad 设备上，Shadowrocket（因其图标为一个发射的小火箭，被国内圈内亲切地称为“小火箭”）是普及度最高、综合使用门槛最低的代理工具。

它具备极其出色的性能与极低的电量消耗，支持包括 Shadowsocks、VMess、VLESS、Trojan、Hysteria2、Snell 等在内的全套协议。相较于需要复杂重写脚本的 Quantumult X 或价格高昂的 Surge，小火箭在“易用性”与“功能深度”之间取得了绝佳的平衡，是几乎所有出海新手的入门必修课。

二、 海外 Apple ID 获取与正版下载避坑指南

初学者面临的最大陷阱是：在大陆地区的 App Store 根本搜不到正版 Shadowrocket！

在国区 App Store 搜索“小火箭”，出来的全部是诱导付费、窃取隐私甚至带有恶意广告的山寨盗版软件。请务必牢记以下正确步骤：

  • 准备一个美区、港区或日区的 Apple ID（可自行注册或购买成品临时号）；
  • 打开 iPhone 自带的 App Store，点击右上角个人头像，滑到最底部点击“退出登录”；
  • 输入海外 Apple ID 登录。切勿在 iPhone 的“设置-Apple ID”全局登录海外号，只需在 App Store 登录，避免 iCloud 数据混淆；
  • 在搜索栏输入 Shadowrocket，认准开发者为 Pan modal（售价为 $2.99 美元）；
  • 下载安装完成后，退出海外账号并切回你原本的国内常用 Apple ID，软件依然可以永久正常使用并更新。

三、 节点导入：一键订阅与扫码步骤

软件安装后仅仅是一个空壳调度器，必须导入机场节点后才能联网。导入主要有两种方法：

方法 1：一键导入订阅（最快捷）

在 Safari 浏览器中登录你的机场用户中心，找到“便捷导入”按钮，点击“导入到 Shadowrocket”。系统会自动弹窗拉起小火箭，并展示“保存”提示，点击右上角保存即可全量载入节点。

💡 导入后节点全部超时，无法刷出网页？
劣质机场易发生上游入口拔线或被墙。推荐使用晚高峰丢包率低于 0.05% 的全内网物理专线节点。

方法 2：手动添加 Subscribe 订阅

  1. 复制机场后台提供的“通用订阅链接”；
  2. 打开 Shadowrocket，点击右上角的 + 号；
  3. 在“类型”栏选择 Subscribe (订阅)；
  4. 将链接粘贴到 URL 栏，备注填写机场名称，点击右上角“完成”；
  5. 软件将自动拉取数十个遍布全球的节点服务器。

四、 核心三大路由模式详解：配置 vs 代理 vs 直连

小火箭主界面上方有一个开关，下方有一个“全局路由”设置，新手必须选择正确的路由模式：

  • 配置 (Config) 模式【强烈推荐】： 智能分流规则模式。访问国内百度、淘宝、微信自动走本地网络；访问 Google、YouTube、GitHub 自动走海外节点。省电、省流量，国内应用不减速；
  • 代理 (Proxy) 模式： 所有流量不论国内外全走代理节点，会导致国内 APP 频繁触发异地登录保护并白白消耗套餐流量；
  • 直连 (Direct) 模式： 不走任何代理，等同于关闭小火箭。

五、 针对 ChatGPT 与 Netflix 的智能规则绑定

进入底部“配置”菜单，默认配置文件通常为 default.conf。

点击配置文件后的感叹号，选择“添加规则”，可以将特定敏感域名强制分流到拥有原生住宅 IP 的美国节点： 

DOMAIN-KEYWORD, openai, PROXY
DOMAIN-SUFFIX, chatgpt.com, PROXY
DOMAIN-SUFFIX, anthropic.com, PROXY
DOMAIN-KEYWORD, netflix, PROXY

设置完成后，即便主策略组选择的是香港节点，当访问 ChatGPT 时小火箭也会自动无缝切换到美国住宅节点进行认证，杜绝由于香港节点引起的 Access Denied 报错。

六、 常见报错与排错清单

1. 初次开启开关提示“添加 VPN 配置”？
点击“Allow (允许)”，并验证 Face ID 或锁屏密码即可。此为 iOS 系统核心权限要求。

2. 节点全部显示超时或红色负数？
前往 iPhone“设置-通用-日期与时间”，开启“自动设置”。时间偏差超过 90 秒会导致 TLS 安全握手全面失败。
