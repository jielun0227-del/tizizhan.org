什么是专线？和普通直连有什么区别？ ▼

专线 (IPLC/IEPL) 是跨国内网点对点物理光纤通道，数据传输全程运行在运营商内部专有线路上，根本不经过公网国际互联网网关，因此在物理层面上根本碰不到 GFW 的任何审查与封锁。

相比之下，普通公网直连（如廉价 VPS）在每晚 20:00~23:00 晚高峰面临骨干网严重的 QoS 限速与高达 20%~40% 的丢包重传。想深入了解两者底层物理架构，请参阅本站深度长文：《IPLC 与 IEPL 专线架构原理解析》。

买了机场为什么连不上？如何快速自检排查？ ▼

购买订阅后连不上的 3 大高频核心原因：
1. 系统时间未同步： 电脑或手机时间如果与北京标准时间偏差超过 90 秒，TLS 加密握手会全部失败。请在系统设置中开启“自动设置时间”；
2. 模式误开为直连： 检查客户端是否误设为了“直连 (Direct)”；
3. 本地防火墙或端口冲突： 检查是否运行了其他代理工具导致 7890 端口被占用。详细排错步骤可查看本站知识库：《Windows 加速器排错指南》 与 《小火箭连接超时排错》。

优惠码如何使用？在哪里输入抵扣？ ▼

在机场官网选定套餐后，进入购物车结算页面，页面中会提供“折价券 / 优惠码”输入框。将从本站 机场专属优惠券频道 (/coupons/) 复制的独家折扣码粘贴进去，点击“应用”即可立享折上折。

买月付还是买年付？如何防范跑路风险？ ▼

强烈准则：新接触的机场坚持月付或季付！ 无论商家打折力度有多大（如 30 元包年 1000G/月），除非是运营 4~5 年以上的顶级老牌，否则任何中小机场都面临上游拔线或恶意圈钱风险。通过月付可以将损失控制在最低限度。

什么是住宅原生 IP？为什么看 Netflix 和玩 TikTok 必须用它？ ▼

住宅原生 IP（Residential ISP IP）是当地真实宽带运营商分配给家庭用户的 IP 地址。流媒体版权商（Netflix, Disney+）与社媒（TikTok）对机房商用 IP 实施了批量拉黑。使用住宅原生 IP 不会触发人机验证，并能解锁 Netflix 4K 全区非自制剧。详见：《Netflix 与 TikTok 解锁指南》。

为什么同一个机场，看网页飞快但打开 ChatGPT 提示 Access Denied？ ▼

因为 OpenAI 目前对中国香港地区的 IP 实施了严格地域封锁。如果你使用的是香港节点，必然会被拦截。请在客户端策略组中将规则分流切换至美国（US）或日本（JP）节点。详见长文：《ChatGPT加速器与 Claude 专用节点调优》。
